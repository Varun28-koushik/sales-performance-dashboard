## Sales Performance Dashboard

Analyzed 9,994 rows of US retail sales data (Sample Superstore dataset) 
to identify profitability patterns across 4 regions and 3 product categories.

## Tools Used
Excel, Pivot Tables, Data Visualisation

## Key Findings
- Total sales: $2.3M | Total profit: $286K
- Furniture had the lowest profit margin despite high sales volume
- Technology delivered the strongest returns
- Built 3 Pivot Tables and a dashboard with KPI metrics and bar charts

## Skills Demonstrated
Data cleaning, ETL, statistical analysis, dashboard development, business intelligence
